# 개인정보 처리방침 점검 에이전트

기관명과 개인정보 처리방침 주소만 넣으면 다음을 자동으로 해 줍니다.

1. 「개인정보 보호법」(2026.9.11. 시행)과 개인정보보호위원회 「개인정보 처리방침 작성지침」(2026.4.)을 기준으로 **적정성 점검**
2. 미흡한 부분의 **개선 방법과 작성 예시**, 근거 조문(국가법령정보센터 링크) 제시
3. **대시보드**: 종합 점수, 상태 분포, 영역별 충족률, 항목별 점수
4. **보고서 PDF 다운로드**: 제목, 기관명, 현행 내용, 미흡한 부분, 개선 방법(예시), 근거
5. **개선된 처리방침** 초안 생성(PDF/HTML)
6. **계층별 처리방침** 자동 생성: 어린이(14세 미만), 청소년(15~18세), 어르신(65세 이상, 큰 글씨)
7. 개인 이름·전화번호·이메일 **자동 비식별(***)** 처리
8. **업종별 점검**: 여행업, 노인복지관, 공인중개사 표준(안) 기준
10. **통합 보고서 내려받기**: PDF · 한글(HWPX) · 워드(DOCX) — 점검 결과, 개선 방법·근거, 개선 후 처리방침(안)(표·라벨·목차), 신구대조표, 계층별 처리방침(안), 생성형 AI 서비스 처리방침(안)을 한 파일로
11. **표 편집**: 동의/비동의 처리 항목, 제3자 제공, 위·수탁, 보호책임자 등은 표로 작성되며, 작성지침 예시 행이 제안되고 칸 수정·행 추가가 가능
9. **MCP 서버**: Claude 등에 커스텀 커넥터(`https://(Worker주소)/mcp`)로 연결하면 대화창에서 바로 점검할 수 있음

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `assets/rules.js` | **점검 규칙**(법령이 바뀌면 이 파일만 수정) |
| `assets/config.js` | 설정(Worker 주소) |
| `assets/engine.js` | **공용 점검 엔진**(비식별·점검) — 웹앱과 MCP 서버가 함께 사용 |
| `assets/export.js`, `assets/hwpx-template.js` | 통합 보고서 HWPX·DOCX 만들기(외부 라이브러리 없음, HWPX 서식은 python-hwpx(Apache-2.0) 기본 문서 기반) |
| `assets/labels.js` | 작성지침 공식 라벨 기호 |
| `assets/app.js` | 화면 동작: 불러오기, 대시보드, 보고서, PDF |
| `assets/audience.js` | 계층별 처리방침 생성 |
| `assets/vendor/` | Chart.js 4.4.1, html2pdf.js 0.10.1(MIT, SRI 검증) |
| `worker/worker-src.js` | Worker 소스: 페이지 불러오기, Claude API, 법제처 API, **MCP 서버** |
| `worker/worker.js` | **Cloudflare에 붙여넣을 파일**(rules + engine + worker-src 자동 합본) |
| `tools/build-worker.mjs`, `wrangler.toml` | Worker 합본 만들기, (선택) 자동 배포 설정 |
| `.github/workflows/` | 매월 법령 개정 확인 알림 이슈, worker.js 자동 빌드·(선택)배포 |
| `SECURITY.md` | 소프트웨어 개발보안 가이드(2021.12.) 49개 항목 준수 점검표 |

## 사용 모드

- **토큰 0 모드**(기본): 규칙 엔진과 템플릿으로 모든 기능이 동작합니다. 비용이 들지 않습니다.
- **API 모드**(선택): `worker/worker.js`를 Cloudflare에 배포하고 `assets/config.js`의 `WORKER_URL`을 넣으면 켜집니다.
  - 안정적인 페이지 불러오기
  - AI 개선 문구
  - AI 계층별 다시 쓰기
  - 법제처 최신 시행일 확인

구축과 배포 방법은 함께 제공하는 **「개인정보 처리방침 점검 에이전트 종합 가이드(PDF)」**를 보세요.

> 이 도구의 결과는 자동 점검 결과일 뿐 법률 자문이 아닙니다.
